
# Simulação discreta de fluxo de energia elétrica com algoritmos Dijkstra aplicados a física de circuitos simplificada (Lei de Ohm).

Essa aplicação simula a passagem de corrente elétrica de um polo a outro, calculando a rota com menos resistência e a corrente elétrica entre o circuito.
Mistura o paradigma de programação orientada a objetos com a funcional, tendo mais características da segunda.

Comentários no código explicam todas as seções e apresentam todas as observações relevantes.
Não é necessária nenhuma biblioteca externa para rodar o código: apenas o Python é o suficiente.

Excelente exercício didático para entendimento da lógica de programação, teoria dos grafos e conceitos fundamentais da física elétrica.
